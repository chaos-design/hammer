## About the docs

Hammer collects the tools and components you use most often day-to-day, covering
the monorepo toolchain and a shadcn/ui-style React component library.

<Cards>
<Card title="Monorepo toolchain" href="/en/docs/guides/installation">

Package discovery, dependency graph analysis, batch publishing and chained task
execution.

</Card>
<Card title="React components" href="/en/docs/components/calendar">

Schedule calendar, colour picker and month picker, compatible with the
shadcn/ui ecosystem.

## Contributing

We welcome your contributions. Whether it's adding a component, improving an
existing one, or fixing a bug, your work makes this project better.

<Callout title="How to contribute" type="info">

- Fork this repository on GitHub
- Create a new branch for your feature or bug fix
- Make your changes and make sure `pnpm verify` passes
- Open a Pull Request with a clear description

</Callout>
