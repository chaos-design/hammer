## 文档简介

Hammer 沉淀日常开发中高频使用的工具与组件，涵盖 monorepo 工具链与
shadcn/ui 风格的 React 组件库。

<Cards>
<Card title="Monorepo 工具链" href="/docs/guides/installation">

包发现、依赖图分析、批量发布与链式任务执行。

</Card>
<Card title="React 组件" href="/docs/components/calendar">

日程日历、颜色选择器与月份选择器，兼容 shadcn/ui 生态。

</Card>

## 贡献指南

我们欢迎你的贡献。无论是新增组件、改进现有组件，还是修复 bug，你的贡献都会让这个项目变得更好。

<Callout title="如何贡献" type="info">

- 在 GitHub 上 Fork 本仓库
- 为你的功能或 bug 修复创建一个新分支
- 提交更改，并确保 `pnpm verify` 通过
- 提交带有清晰描述的 Pull Request

</Callout>
